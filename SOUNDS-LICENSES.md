# Sound sources and licenses

The MIT license in LICENSE covers Thock's code only. Each sound pack keeps the license listed below.

Every sound in `packs/` is a genuine recording from the sources below. Licenses were checked on each
source page on 2026-11-03 (Asia/Manila). Freesound files were taken from the public HQ preview
(same recording, same license as the original upload). All files were trimmed, split into
press/release, resampled to 48 kHz mono and level-matched by `tools/build_packs.py`. Some special-key
samples (noted below) are pitch-shifted copies of the same recording. Apart from Coding Relax (last section),
no sounds from Keeby or any commercial product are used.

## Buckling Spring (`packs/buckling`)
- Source: *bucklespring* by Ico Doornekamp, https://github.com/zevv/bucklespring (commit 43274ed), `wav/` directory:
  his own per-key recordings of an IBM Model M (press and release for each key).

## Changes to earlier packs (2026-11-03)
- Clicky Blue: the phone-recorded spacebar (UberBosser) was replaced with a lower-pitched copy of the Professor-Syntax MX Blue
  recording so the pack is one consistent, clean source. UberBosser's file is no longer used.
- Deep Clear: stronger noise reduction and a gentle noise gate on the humi74 recording to remove background hiss.
